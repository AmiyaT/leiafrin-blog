关于这里

你好，我是明月。这是一个用纯静态网页搭建的个人博客——没有服务器、没有数据库，文件往任意托管平台一放就能访问。

我写的东西很杂：技术踩坑记录、读完一本书的碎碎念、以及一些不成体系的思考。更新随缘，但每一篇都是认真写的。

这个站点怎么搭的

  • 纯 HTML / CSS / JavaScript，零依赖、零构建步骤
  • 文章是普通的 HTML 文件，放进 posts/ 目录即可
  • 首页列表由 assets/main.js 读取 posts-data.js 自动生成
  • 未来有服务器了，整套文件夹原样丢进网站根目录就能跑
