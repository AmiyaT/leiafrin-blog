## Decap CMS 重构（在线编辑，不用每次上传）
- 用户新需求：在线修改，不用每次改完都重新上传。
- 方案：GitHub + Decap CMS（无服务器、纯前端后台）。
- 内容模型从「posts/ 下每个文章一个 HTML 文件夹 + posts-data.js」改为：
  - `content/site.json` → 站名/品牌/首页简介/关于页
  - `content/posts.json` → 所有文章数组（含 slug/title/date/excerpt/tags/body-Markdown）
  - `assets/site.js` → 用 fetch 读取 JSON，marked 渲染 Markdown，统一渲染首页/文章/关于
  - `post.html?p=slug` → 文章详情页（单页模板）
- 新增 Decap 后台：`admin/index.html` + `admin/config.yml`（collections: site 站点设置 + posts 文章列表）。
- OAuth 代理：提供一个 Cloudflare Worker 代码（做 GitHub code→token 交换），Decap config.yml 的 base_url 指向该 Worker。Worker 需配 CLIENT_ID/SECRET（来自 GitHub OAuth App）。
