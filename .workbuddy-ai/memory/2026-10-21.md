# 2026-10-21 工作日志

## 纯静态个人博客站点搭建
- 用户需求：有域名、不想管服务器，建个人博客；后续可能用 1Panel / 自有服务器。
- 方案：零依赖纯静态站点（HTML/CSS/JS，无构建、无数据库），最大化"服务器就绪"可移植性。
- 文件结构：`index.html`(首页列表, JS 渲染) / `about.html` / `assets/{style.css,posts-data.js,main.js}` / `posts/<slug>/index.html`(目录式干净链接)。
- 已验证：本地 `python -m http.server` 下所有页面与资源均返回 200。
- 关键点：文章用目录式链接 `/posts/xxx/` 而非 `.html`，静态托管与 nginx/Apache/1Panel 均原生支持，便于将来迁移。
- README 写了：免费托管(Cloudflare Pages/GitHub Pages/Netlify)、绑域名(DNS CNAME+SSL)、1Panel/裸 nginx/Apache 迁移步骤、写新文章方法。
- 用户确认此静态方案可用 1Panel 建站（静态网站根目录上传文件即可）。
